How I test AI on finance work, in plain words.

- Every case is built on a real document: a filing, a trade confirmation, a corporate action notice. Where something had to be constructed, such as an account position, the case file says so.
- The work is graded step by step, not on the final answer alone. Which document governs, does the calculation tie out, does the action follow.
- A few mistakes fail the run automatically, whatever else went right: a wrong fiscal period, a unit error, an invented number, a payment on superseded terms.
- Every model run is published, so anyone can re-grade it.
- The grader is tested too. Four adversarial passes before the first live run, and an outside review in September that found four more gaps. All fixed, all now permanent checks.

The thing I still check is the grader itself. Every round so far has found something.

Six workflows, eight models, three vendors, and the report is on SSRN, link in the first comment. What would you add to the list of automatic failures?
