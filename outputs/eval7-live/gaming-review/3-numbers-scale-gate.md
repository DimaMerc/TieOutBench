## Failed attacks (the grader held)

- **TNA off every scale factor** (+3.5%, x10, billions): gate quiet by design; TNA alone -> C2 0.722, case 0.9611; TNA + TA + NAV all wrong -> C2 **0.222** (C2.scale pays 4/18 for any garbage), case 0.8911. C3 and D1 stay 1.000: C2 never cascades into them. An empty or deleted C2 scores the same 0.8911.
- **Empty answer** `{}` (or a junk key only): 0.0 on both cases. The free C2.scale credit (and, on C, C3.direction) never survives because the absent P1 fires GATE.DATE (hard) and GATE.REGIME; the "absence is not evidence" rule applies to GATE.SCALE only, so the free credit (C2.scale's 4/18 above, and row 10's empty direction on C) exists only beside a correct P1.
- **NAV mis-scaled by exactly the share count, by x100, by /100, by /shares**: GATE.SCALE fires every time (0.6100). The 5% window is exact (x1049 fires, x1051 quiet; shares x1.04 fires, x1.06 quiet).
- **Inside the 2% band** (TNA / TA / NAV +1.9% and -1.9%): no gate, atom fails only (0.9611 / 0.9689). The `abs(ratio-1) <= 0.02` early exit is dead code: 0 of 260,015 (model, gold) pairs change outcome with it removed, because no scale factor sits within 7% of 1.
- **Strings with separators, currency and percent signs** are credited (row 12 list); NaN, "inf", "1e400" parse but fail the atoms with no gate and no crash.
- **Threshold flags answered as a consequence** (`exceeds_reprocessing_pct:false` on the break, pre-release): C3.thresholds 0, B 0.9718 - held, and the SCHEMA now says "the arithmetic test only, whatever the review stage". `"true"` / `"yes"` / `"y"` / `"1"` / `1` / `"TRUE"` are credited; the placeholder echo `"<true if ...>"` is not.
- **Incentive to abstain on exactly the gated figures** (held, but note it): a blank C2 scores 0.8911 against 0.5400 for the same C2 mis-scaled x1000 or /1000; inverted numbers with the direction omitted score 0.8703 against 0.7082 with "overstated". The gates fire on evidence by design, so nulling the watched figures dodges them.
- **Reasonableness flag true with the move numbers missing or wrong** (B and C): C3.expected 0 (0.9624); the flag alone earns nothing. expected_move as a fraction (0.04, "0.04") and the deviation with the opposite sign fail (0.9624), no gate.
- **Direction "none" on the break**: fails C3.direction only (0.9624), GATE.SIGN stays quiet as documented, and nothing else in C2/C3/D1 catches it in isolation; with zero error numbers and false flags but HOLD in D1 the answer scores 0.8400 with no gate (C3 can say "no error" while D1 holds: no cross-checkpoint check).
- **Opposite sign convention with the right direction**: C3.error fails (0.9435), D1.localize too if D1 follows (0.9080); the sign gate is silent, consistent with the hook reading the direction string.
- **Tolerance edges are exact**: NAV +-0.0002 inclusive (51.9910 and 51.9914 pass, 51.99095 and 51.99145 fail); TNA, TA, TL +-$1.00; error +-0.001 / +-$1.00 / +-0.01 pp. On C, a per-share "error" up to 0.001, a fund error up to $1.00 and 0.01 pp are credited as a tie.
- **Negative zero and tiny floats** (-0.0, 1e-13, 1e-320): credited as zero on C, no crash. Placeholder echo of the thresholds (`"<true if ...>"`): fails.
- **Type-confusion fuzz**: 1,116 runs (every C2/C3 field x 31 odd values x both cases): 0 crashes, 0 gate firings from odd values; the only AllPass-preserving fields are the four ungraded ones, the flag whose odd value equals gold, and (on C) direction / zero-error fields.
- **Phantom errors on C** (error -0.75, direction understated or overstated): fail C3.error and C3.direction only; GATE.SIGN is silent (not an inversion) and GATE.SCALE cannot fire on the error fields because gold is 0.

## Pattern

The numeric atoms are tight and behave exactly as specified at their tolerance edges; every finding sits in the string and number plumbing around them. `_norm_direction`, `_bool` and `_num` accept or reject by prefix and string shape, so placeholder echoes and hedges are credited (AllPass for "understated|overstated|none"), natural phrasings fail, and the two numeric gates are driven by those same parsers: GATE.SIGN by `startswith("OVER")` and GATE.SCALE by a five-figure, positive-ratio, six-factor test, so each can be evaded (sentence-form inversion, x10, sign-flipped scaling, unread figures) and tripped by a right answer ("Overall understated", "207964686,19"). Fix shape: whole-token enum match that rejects multi-option strings; take the sign from the numbers as well as the word; test |ratio| against powers of ten and add liabilities, percentages and the D1 figures to the evidence; make `_num` locale- and accounting-aware or fail closed on commas; grade or drop the four unscored fields; guard `_num` and the section reads against OverflowError and string sections.
