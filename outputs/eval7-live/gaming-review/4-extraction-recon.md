## 3. Grader crashes on malformed sub-objects (fail-open, not a zero)

The grader raises instead of scoring. `outputs/run_live_eval7.py` calls `run_case` with no `try`, and the grid runner logs
"FAILED ... skipped, never retried", so the cell simply has no score: a malformed answer on a hard case removes that case from the
average. Crash map (Z2, node replaced by a wrongly typed value; the oracle is otherwise perfect):

| Path | Value that crashes | Exception | Natural source |
|---|---|---|---|
| `E1.citation.verbatim` | a list of strings (`["line_id=SWAP-B"]`), a number, an object | AttributeError (`.lower`) | a model quoting two lines |
| `E2.index` | `"5100"`, `[5100, 5000]`, `5100` | AttributeError (`.get`) | |
| `E2.capital_stock` | `"none"`, `[{"creations_shares": 0}]`, any non-empty list | AttributeError (`.get`) | a prose answer for "no creations or redemptions" |
| `E1.stale_flags` | `1`, `true` | TypeError (not iterable) | |
| `E1.admin_lines`, `E1.admin_liabilities`, `E2.swap_statements`, `C1.recon`, `C1.exceptions` | a non-zero number or `true` | TypeError (not iterable) | |
| `_injected_penalties` (harness key) | `5` | TypeError | |

Repro: K, Z2. (E1, E2 and C1 returned as top-level lists, as the real 2B run did, do not crash: `_g` guards the top level only.)

## 4. Attacks that failed (the grader held)

- **E1.cite from the wrong package or the wrong numbers**: the break totals block on the clean package, the recomputed totals on the break package, the break exceptions line on the clean package all score 0 (A4c, A5, A5b). ## 7. Pattern

E1, E2 and C1 are graded by resemblance to gold, not by the work: ids by `.upper()`, statuses by an exact enum after stripping punctuation, exceptions by substrings, citations by token overlap with gold strings (never with the package), flags by iterating whatever type arrives. So anything the handlers never read (reconciliation values, dates, counterparties, price dates, extra keys, extra rows, invented prices outside D2) can be wrong or invented up to 1.000/AllPass, while any deviation from the SCHEMA's literal shape scores as "nothing read" and, for ids, trips the hard fabrication gate. Everything on this surface that is worth points (E1.stale, E1.cite, C1.match, C1.exceptions, C1.structure) can be earned by transcribing the administrator's own pricing-exception report (L3: C1 = 1.000, E1 = 0.357 with no figure anywhere), and the one break in the gold case is always flagged by that report, so none of it measures independent reconciliation.

Fix direction, one line each: (1) grade `independent_value` and `admin_value` in C1.match or add a values atom; (2) extend n_halluc to recon ids, price/index/capital-stock keys and scan every model number outside D2 for the withheld close; (3) verify the verbatim is a whitespace-normalised substring of the rendered package and carries the evidence tokens (STALE_PRICE or price_date) for the reading; (4) normalise ids (strip, collapse separators), accept str/list/map for flags and a status synonym table; (5) require the exception row to carry the quantified gap, match keywords on word boundaries and not negated, and tolerate a no-op row on the clean case; (6) wrap grading in try/except and score a crash as 0 with provenance `grader_error`.
